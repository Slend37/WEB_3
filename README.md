# Сайт для обмена книгами

## Реализованные функции:
1) Возможность загрузить информацию о новой книге на сайт
2) Возможность просмотреть инфомрацию о других загруженных книгах
3) Возможность регистрации
4) Возможность добавления новых авторов
5) Возможность оставлять комментарии под книгами и просмотривать комментарии других пользователей
6) Страница About, которая рассказывает о проекте
7) Главная страница с общим каталогом книг

## Запуск:
```bash
python manage.py runserver
```
